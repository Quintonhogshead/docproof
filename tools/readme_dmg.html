DocProof

Version @VERSION@ · built @BUILT@

DocProof reads a manuscript and marks up grammar and typing mistakes as tracked changes you accept or reject in Word — or in InDesign, if you work in layouts. It also prepares a manuscript for layout, tagging every paragraph with the house style names so it drops into your InDesign template.

What you need

  • A Mac from 2021 or later (Apple Silicon — M1, M2, M3, M4). This build will not run on an older Intel Mac.
  • macOS 11 Big Sur or newer.
  • An API key from Anthropic, OpenAI or Google — see below.

1. Install it

Drag DocProof onto the Applications shortcut in this window. If you are replacing an older DocProof, say yes to replacing it.

2. The first time you open it

DocProof is not signed with Apple, so macOS stops it once. This is expected and it only happens the first time.

  1. Double-click DocProof in Applications. macOS will refuse to open it. Click Done — do not move it to the Trash.
  2. Open System Settings → Privacy & Security and scroll down. There will be a line saying DocProof was blocked, with an Open Anyway button. Click it.
  3. Confirm with your password or Touch ID. DocProof opens, and every time after this it opens normally.

On older versions of macOS there is no Privacy & Security prompt — instead, right-click DocProof in Applications, choose Open, and click Open in the dialog.

3. Add your AI key

Go to Settings in DocProof and paste a key from Anthropic, OpenAI or Google. The Test button next to it makes one cheap call so a wrong key fails there rather than in the middle of a job.

DocProof sends your documents to whichever of those services the key belongs to, and they bill the owner of that key directly. Nothing goes to us. Keys are stored in your Mac's Keychain — never in a file, never shown back to the screen.

4. Staying up to date

Settings → This version shows exactly which build you have. If whoever sent you DocProof also gave you a GitHub token, paste it there once. From then on, DocProof checks quietly when it opens, and when a newer version is ready a bar appears at the top with an Update now button. One click installs it and DocProof reopens itself — your old copy goes to the Trash in case you ever want it back. Nothing updates without that click, and it will politely refuse while a document is being worked on.

No token? Nothing breaks — just ask whoever sent you DocProof when there is a newer build, and install it from the new disk image the same way you did this one.

Optional extras

  • LibreOffice — only if you want to drop .doc, .rtf, .odt or .txt manuscripts in. DocProof converts them at drop time. .docx and .idml need nothing.
  • Adobe InDesign — only for the Place into the InDesign template button. Point Settings at your template first. macOS will ask once for permission to let DocProof control InDesign.

Where things end up

Finished documents go to ~/Documents/DocProof/, in a folder named after each document. DocProof runs entirely on your Mac — the only thing that leaves it is the text of the documents you ask it to review, which goes to the AI service whose key you set up.

# Mara Ellison demo site

This folder is a clearly fictional demo gallery entry for the Author Website Studio. Mara Ellison, *The Shape of Returning*, and *Where the River Ends* are invented for local preview and evaluation; they are not real author, book, press, retailer, or social proof records.

`site.json` is a complete `SiteSpec` payload. The public contact address is the visible demo address `hello@example.com`, and the empty links, praise, and purchase fields are intentional. The homepage call to action has an empty URL so the renderer can attach its internal books route.

The two SVGs in `assets/` are original code-native placeholder covers made for this demo. They use only inline vector shapes and system fonts, with no scripts, external images, network resources, or photoreal portrait. `assets.json` records the approved asset metadata and hashes the exact SVG bytes used by the preview.

      DocWatch

      One folder in Google Drive, looked at a few times a day. Anything in it that looks like a manuscript and hasn't been prepared yet is prepared, and the results go back beside the original — so a book that arrives overnight is ready for a designer by morning. The author's own file is never moved, renamed or changed.

      The Google sign-in DocProof uses

      DocProof needs its own OAuth client to ask Google for permission — five minutes in the Google Cloud console, once. docs/watch.md walks through it, including which consent screen to pick.

      Output archive

      Every finished job — reviews, formatting, promo, from the app or the watched folder — is copied into one Drive folder, sorted into Reviews, Prep and Promo by month. It is the durable record: the deliverables outlive a redeploy, and the whole list can be rebuilt from it. Turning it on also files everything already finished.

      Drive archive recovery
      
      
      If this server ever comes up with its job list gone — a
        lost or replaced disk — rebuild it from the Drive output archive. Every
        job's record is recreated from its saved copy; documents come back the
        first time anyone opens them. Nothing already here is touched, and it is
        safe to run more than once. A fresh, empty server does this on its own;
        this is the button for doing it by hand. Set the archive up under
        DocWatch first.

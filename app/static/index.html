      DocWatch

      One folder in Google Drive, looked at a few times a day. Anything in it that looks like a manuscript and hasn't been prepared yet is prepared, and the results go back beside the original — so a book that arrives overnight is ready for a designer by morning. The author's own file is never moved, renamed or changed.
